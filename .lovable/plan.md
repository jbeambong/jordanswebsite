# Rendre ton GitHub lisible pour un recruteur

## Ce qu'un recruteur regarde
1. Ta page de profil (github.com/jbeambong) : photo, bio, dépôts épinglés.
2. Le fichier de présentation (README) affiché sous les fichiers du dépôt. C'est lui qui dit « ceci est un site web ».
3. La description courte et le lien vers le site, à droite du dépôt.

Aujourd'hui, la présentation de ton dépôt contient juste ta toute première demande en français. Un recruteur ne comprendrait pas de quoi il s'agit.

## Ce que je fais (dans le code)
Je réécris la présentation en anglais :
- Titre et une phrase : « Personal website of Jordan Béa Mbong — Marketing & Tech »
- Lien visible vers https://jordanbeambong.com
- Une capture d'écran de la page d'accueil
- Ce que contient le site : Portfolio (études de cas), Writing, Experience, EN/FR
- Comment c'est fait : React, TypeScript, Tailwind, site 100 % statique, contenu modifiable dans `src/data/`
- Comment le lancer en local (3 commandes)

## Ce que tu fais sur github.com (2 minutes)
- Dans le dépôt, roue dentée « About » : ajoute une description et le lien jordanbeambong.com.
- Settings → passe le dépôt en Public (il est privé par défaut, un recruteur ne le voit pas sinon).
- Sur ton profil : « Customize your pins » → épingle ce dépôt.
